Context-scaling experiment — pre-specified plan v1 (ACCESS-034), written 2026-10-31 BEFORE any call on L1/L2.

Question. The manuscript claims only that a benefit of bounded reading (M2R) over whole-document extraction (B0)
"is plausible but was not tested" for documents beyond the effective context. This experiment tests it on the frozen
Open PCA ground truth (openpca-gt-v1, unchanged) by embedding the test document in natural, unrelated engineering text.

Documents (scripts/build_padded.py; data/frozen/context-scaling/padded-meta.json; text files gitignored because the
TMT OAD licence is not stated):
  L0  Open PCA alone, 36,488 tokens (existing runs: main-v1 B0, main-v2 M2R; no re-run)
  L1  first 46K tokens of FAA REMH + Open PCA + first 46K tokens of TMT OAD = 127,287 tokens (Open PCA starts at 45,630)
  L2  full FAA REMH + Open PCA + full TMT OAD = 240,915 tokens (Open PCA starts at 72,002)
  Distractors contain no R<d>.<d>.<d>(<n>) identifier (asserted in the script).

Arms and settings. B0 (pipeline.py, frozen v1) and M2R (pipeline_v2.py, frozen v2.1 hash method-v2.1-posthoc.sha256),
code unchanged; chunk size 1,500; models gpt-6.1-sol and claude-opus-5-5; 3 runs each per level. Prompts unchanged.
If a provider rejects an input as too long, the run is recorded as a failure with recall 0 for that arm (a real
limitation of whole-document reading), and reported separately; no truncation or retry with a shorter input.

Scoring. score.py and analyze_all.py unchanged (full, words, identity, qty, wrong merges, NE linked, spurious).

Primary hypotheses (per model):
  H1  B0 full recall at L2 is lower than at L0.
  H2  The drop L0->L2 is larger for B0 than for M2R (difference of differences > 0).
Decision rule: paired component bootstrap (28 components, 10,000 resamples, seed 20261031) of
  D = [B0(L0) - B0(L2)] - [M2R(L0) - M2R(L2)]; H2 supported for a model if the 95% interval of D excludes 0.
  H1 supported if the 95% interval of B0(L0) - B0(L2) excludes 0. L1 is reported descriptively.
Secondary (descriptive): spurious allocations from distractor chunks, learned correspondence and its support,
cost (calls, input tokens, max per-call input).
No change to the method or the ground truth is allowed after the first L1/L2 call; any deviation is logged.
